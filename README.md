# Furniture Sales Data Analysis using Python

## 📌 Project Overview

This project analyzes a furniture sales dataset using Python. The analysis includes data cleaning, exploratory data analysis (EDA), aggregation, and data visualization to generate business insights.

## 🛠️ Tools & Libraries

- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
